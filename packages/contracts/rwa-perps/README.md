# rwa-perps JS

JS library for interacting with the [Soroban](https://soroban.stellar.org/) smart contract `rwa-perps` via Soroban RPC.

This library was automatically generated by Stellar CLI using a command similar to:

```bash
stellar contract bindings ts \
  --rpc-url <RPC_URL> \
  --network-passphrase "<NETWORK_PASSPHRASE>" \
  --contract-id <CONTRACT_ID> \
  --output-dir packages/contracts/rwa-perps
```

For testnet, substitute the placeholders as follows:

```bash
stellar contract bindings ts \
  --rpc-url https://soroban-testnet.stellar.org \
  --network-passphrase "Test SDF Network ; September 2015" \
  --contract-id <RWA_PERPS_TESTNET_CONTRACT_ID> \
  --output-dir packages/contracts/rwa-perps
```

The network passphrase and contract ID are exported from [index.ts](./src/index.ts) in the `networks` constant. Once the contract is deployed to additional networks, update `networks` accordingly.

# To publish or not to publish

This library is suitable for publishing to NPM. You can publish it using the `npm publish` command.

But you don't need to publish it to use it inside this monorepo. It is registered as a workspace package and can be imported directly:

```json
"dependencies": {
  "@neko/perps": "*"
}
```

# Use it

```ts
import { Client, networks } from "@neko/perps";

const client = new Client({
  ...networks.testnet,
  rpcUrl: "https://soroban-testnet.stellar.org",
  publicKey: undefined,
});

// Open a perpetual position
await client.open_position({
  trader: "G...",
  rwa_token: "C...",
  size: 100_0000000n,
  leverage: 500,
  margin: 10_0000000n,
});
```

Or via the shared contract client pattern used in `apps/web-app/src/contracts/`:

```ts
import * as Client from "@neko/perps";
import { rpcUrl, networkPassphrase } from "@/lib/constants/network";

export default new Client.Client({
  networkPassphrase,
  contractId: Client.networks.testnet.contractId,
  rpcUrl,
  publicKey: undefined,
});
```

As long as your editor is configured to show TypeScript documentation, pausing after `client.` will list all exported methods with inline documentation generated from the original contract source.
